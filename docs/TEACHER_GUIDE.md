# 교사용 빠른 안내 — 꺾은선그래프 연구소

## 수업 전 (10분)
1. 첫 화면 오른쪽 아래 **교사 관리실** → **처음이에요 → 교사 계정 만들기** (가입 코드는 서버 관리자에게)
2. **＋ 새 학급 만들기** → 학교 검색 → 학년·반 → 학급 코드 정하기 → **QR 완성**
   (QR은 [크게 보기]로 전자칠판에 띄우거나 [인쇄용 카드]로 나눠 줘요)
3. **학생 명단** 탭에 `번호 이름`을 한 줄씩 붙여 넣고 **명단 등록하기**
   (학생은 PIN 없이 학급 코드 + 내 이름 누르기로 들어옵니다)
4. **단계·조사 설정** 탭에서 기상자료 포털 안내 문구를 확인하세요(포털 메뉴가 바뀌면 고쳐 주세요).

## 1차시 — 기상자료 탐험실 (교과서 118~121쪽)
- 학생: 학급 코드 + 내 이름 누르기로 입장 → 제1장에서 지역·기간 정하기 → 포털에서 폭염일수 찾기 → 표 → 그래프 → 제출
- 이 장을 마쳐야 다음 장이 열립니다. 결석·기기 문제 학생은 **진행 현황 → 자세히 → 예외 허용**
- 학생이 표를 잘못 적고 제출했다면 **자세히 → 기상자료 다시 하게 하기**

## 2차 활동 — 나의 주제 꺾은선그래프
- 학생이 25가지 주제 중 직접 골라, 2026년 1~11월 자기 기록 → 자료표 → 꺾은선그래프 순서로 만들어요.
- 한 사람이 꼭 낼 그래프 수는 [학생 주제 → 주제 묶음·방식]에서 정해요(기본 3개). 시간이 남는 학생은 더 만들 수 있어요.
- [학생 주제 → 학생별 주제]에서 누가 무엇을 골라 몇 개를 냈는지 볼 수 있어요.

## 3차 활동 — 우리 고장 꺾은선그래프 (교과서 122~123쪽, 수학익힘 78~79쪽)
- 학생이 진주 자료를 하나 골라요. 관광지 입장객 수(진주성·산림박물관·월아산 숲속의 진주·진양호 동물원·진주시립이성자미술관·진주익룡발자국전시관)는 공공데이터포털 「경상남도 주요관광지점 입장객 현황」(2017~2022년) 자료표가 화면에 함께 나와요. 도시공원 수·인구·직접 찾은 자료는 누리집에서 찾아요.
- 누리집·뉴스 링크가 새 창으로 열려요. 찾은 연도별 값 4~6개와 출처를 표에 적고 [표 확인하기]를 눌러요.
- 그래프를 그려 제출한 뒤, 다음 해 값을 예상하고 이유를 써요(교과서 122쪽 마지막 물음). 친구 자료와의 관계는 선택이에요(123쪽 2번).
- **우리 고장 바꾸기**: [설정 → 3차 우리 고장 자료]에 시·군 이름(예: 창원시, 하동군, 수원시)을 적고 [이 지역 자료로 바꾸기]를 누르면, 관광지 입장객 수·도시공원 수·인구 자료가 그 지역 이름과 링크로 바뀌어요.
  - 경상남도 18개 시·군은 공공데이터포털 관광지 자료(2017~2022년)가 들어 있어 입장객이 많은 관광지 6곳의 자료표가 학생 화면에 함께 보여요.
  - 다른 시·도는 학생이 관광지식정보시스템에서 입장객 수를 직접 찾아요.
  - 학급을 만들 때 학교 주소로 시·군을 알아내 미리 채워 둬요.
- 링크나 주제는 같은 곳에서 하나씩 고칠 수도 있어요. 기사마다 세는 방법이 달라 숫자가 다를 수 있다는 점도 함께 이야기해 보세요.

## 이어서 하기(저장)
- 학생이 입력한 내용은 모두 서버에 저절로 저장돼요.
- 다음 시간에는 학급 코드를 넣으면 우리 학교·학년·반과 이름 목록이 나와요. 내 이름을 누르면 하던 곳부터 이어서 해요.

## 작품 전시관
- 승인한 작품만 같은 학급 전시관에 걸려요. 1차·2차·3차로 나누어 볼 수 있고, 친구 이름을 누르면 그 친구의 작품만 모아 볼 수 있어요.

## 자료 내려받기
**자료 내려받기** 탭: 학생별 응답, 학급 집계, 진행 현황, 기상자료 결과(CSV, 엑셀에서 열림)

## 자주 묻는 질문
- **학생이 새로고침하면?** 입력한 내용과 보던 쪽이 서버에 저장되어 그대로 이어집니다.
- **다른 반이 우리 반 작품을 볼 수 있나요?** 없습니다. 서버가 학급을 확인합니다.
- **0과 ‘기억나지 않음’의 차이는?** 0은 ‘한 번도 안 함’, 기억나지 않음은 집계에서 빠지고 응답 수에 표시됩니다.
