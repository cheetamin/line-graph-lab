# 교사용 빠른 안내 — 꺾은선그래프 연구소

## 수업 전 (10분)
1. 첫 화면 오른쪽 아래 **교사 관리실** → **처음이에요 → 교사 계정 만들기** (가입 코드는 서버 관리자에게)
2. **＋ 새 학급 만들기** → 학교 검색 → 학년·반 → 학급 코드 정하기 → **QR 완성**
   (QR은 [크게 보기]로 전자칠판에 띄우거나 [인쇄용 카드]로 나눠 줘요)
3. **학생 명단** 탭에 `번호 이름`을 한 줄씩 붙여 넣고 **등록하고 PIN 만들기** → PIN 카드 인쇄
   (PIN은 이때 한 번만 보입니다. 잊은 학생은 [PIN 새로 만들기])
4. **단계·조사 설정** 탭에서 기상자료 포털 안내 문구를 확인하세요(포털 메뉴가 바뀌면 고쳐 주세요).

## 1차시 — 기상자료 탐험실 (교과서 118~121쪽)
- 학생: 학급 코드 + 번호 + PIN으로 입장 → 제1장에서 지역·기간 정하기 → 포털에서 폭염일수 찾기 → 표 → 그래프 → 제출
- 이 장을 마쳐야 다음 장이 열립니다. 결석·기기 문제 학생은 **진행 현황 → 자세히 → 예외 허용**
- 학생이 표를 잘못 적고 제출했다면 **자세히 → 기상자료 다시 하게 하기**

## 2차시 — 주제 투표와 월별 조사
1. **주제·투표** 탭: 추천 투표 받기 켜기 → 결과 보며 함께 의논
2. 조사할 주제를 체크하고 **조사 주제 저장** (여러 개 가능)
3. 학생이 1~11월 값을 입력·제출 → **학급 집계** 탭에서 실시간 확인
4. 모두 제출했으면 **단계·조사 설정**에서 월별 조사를 마감하세요. (자료표 단계에서 값이 바뀌지 않도록)

## 3차시 — 자료표와 그래프
- 자료표: 기본값은 ‘친구들 응답 목록을 보고 직접 더하기’. 어려워하면 설정에서 ‘학급 합계 옮겨 적기’로 바꿀 수 있어요.
- 10번(배구 서브)은 평균, 19번(저축)은 합계/평균만 공개됩니다.
- 그래프: 학생이 [확인하기]를 통과해야 제출할 수 있어요.

## 4차시 — 작품 전시관
- **작품 승인** 탭에서 승인(전시) / 다시 그리기 요청(한마디 남기기) / 삭제
- 전시관 이름 표시는 설정에서 이름·번호·별명 중 선택

## 자료 내려받기
**자료 내려받기** 탭: 학생별 응답, 학급 집계, 진행 현황, 기상자료 결과(CSV, 엑셀에서 열림)

## 자주 묻는 질문
- **학생이 새로고침하면?** 입력한 내용과 보던 쪽이 서버에 저장되어 그대로 이어집니다.
- **다른 반이 우리 반 작품을 볼 수 있나요?** 없습니다. 서버가 학급을 확인합니다.
- **0과 ‘기억나지 않음’의 차이는?** 0은 ‘한 번도 안 함’, 기억나지 않음은 집계에서 빠지고 응답 수에 표시됩니다.
