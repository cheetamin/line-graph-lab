# 꺾은선그래프 연구소

초등학교 4학년 2학기 수학 5단원 「꺾은선그래프」의 ‘자료를 조사하여 꺾은선그래프로 나타내어 볼까요?’(118~121쪽)를 바탕으로 만든 동양풍 고서 탐험서 웹앱입니다.
학생은 기상청 자료를 조사해 표와 꺾은선그래프를 직접 그리고, 학급 친구들과 함께 2026년 월별 경험을 조사해 자료표와 그래프를 완성한 뒤, 교사가 승인한 작품을 책장을 넘기며 감상합니다.

## 바로 쓰기 — 두 가지 방법

| | ① GitHub Pages 판 (로그인·설치 없음) | ② 서버 판 (학급 운영용) |
|---|---|---|
| 주소 | `https://<계정>.github.io/<저장소>/` | Render·학교 서버 등에 올린 주소 |
| 준비 | 저장소 Settings → Pages에서 `gh-pages` 브랜치 선택 | `render.yaml`로 배포(아래 참고) |
| 자료 저장 | **그 기기의 브라우저 안에만** 저장 | 서버 DB에 저장 |
| 교사가 학생 작품 보기·승인 | 같은 기기에서만 | 어느 기기에서든 |
| 알맞은 때 | 체험, 한 기기로 시연, 전자칠판 수업 | 학생들이 각자 기기로 참여하는 실제 수업 |

GitHub Pages 판은 체험 학급(학급 코드 `DEMO26`, 교사 `demo`/`demo1234`, 학생은 이름만 누르면 입장)이 들어 있고, 새 학급도 만들 수 있지만 자료는 브라우저마다 따로 저장됩니다.
`npm run build:pages`로 `dist-pages/`를 만들고 그 내용을 `gh-pages` 브랜치에 올리면 됩니다.

## 전체 관리자
- 입장 화면 → [교사 관리실] 탭 → [전체 관리자 들어가기]
- 운영 현황(학급·선생님·학생·작품 수), 학급 목록, 학생·교사 만족도 결과(이름 없이), 지역·학교별 현황, CSV 내려받기
- **서버 판 전용**: 서버 환경 변수 `ADMIN_PASSWORD`로 비밀번호를 정해요. 비밀번호는 코드나 저장소에 넣지 않아요(공개 저장소라 해시도 넣지 않음).
- GitHub Pages 판은 자료가 브라우저마다 따로 있어 관리자 화면을 쓰지 않아요.

## 학습 흐름 — 꺾은선그래프 세 번 그리기

| 활동 | 내용 | 열리는 조건 |
|---|---|---|
| 1차 기상자료 탐험실 (필수, 118~121쪽) | 기상자료개방포털에서 연도별 폭염일수 5개 조사 → 표 → 직접 그래프 → 제출 | 처음부터 |
| 2차 나의 주제 그래프 | 25개 주제 중 직접 골라 2026년 1~11월 내 기록 → 자료표 → 그래프. 꼭 낼 수(기본 3개) 이상, 시간 남으면 더 | 1차 완료 |
| 3차 우리 고장 그래프 (122~123쪽) | 선생님이 정한 시·군의 관광지 입장객 수(경남 18개 시·군은 공공데이터포털 자료표 제공)·도시공원 수·인구 → 표 → 그래프 → 다음 해 예상. 지역 이름만 적으면 자료가 바뀜 | 1차 완료 |
| 작품 전시관 | 승인된 같은 학급 작품, 1·2·3차로 나누어 보기, 친구 이름 누르면 그 친구 작품 모아 보기 | 처음부터 |
| 만족도 조사 | 학생: 1·2·3차를 모두 제출한 뒤 / 교사: 작품을 한 개 이상 승인한 뒤. 결과는 이름 없이 모아 보기·CSV | 조건 충족 시 |

학생은 학급 코드를 넣으면 나오는 학교·학년·반과 이름 목록에서 내 이름을 눌러 들어오며(PIN 없음), 하던 곳부터 이어서 합니다.

모든 잠금은 화면뿐 아니라 **서버에서 검사**합니다. 교사는 단계별로 열기·잠그기, 학생별 예외 허용을 할 수 있습니다.

## 그래프 그리기 기능
- 모눈종이에 직접 점 찍기(마우스·손가락·펜), 누르고 있는 동안 위치·값 말풍선과 안내선 표시, 끌어서 위치 고치기
- 점→점 눌러 선분 잇기(끌어서 잇기도 가능), 지우개, 되돌리기·다시하기, 모두 지우기
- 확대·축소·화면 맞춤(두 손가락 확대, Ctrl+휠), 화면 이동
- 키보드로도 그리기(←→ 이동, ↑↓ 값, Enter 잇기, Delete 지우기)
- 물결선(세로축 시작 값) 선택 가능
- 자동 저장(0.9초) + 중간 저장 버튼 + 인터넷이 끊기면 기기에 임시 보관
- [확인하기]는 서버가 검사: 제목·축·단위·눈금 칸 수·점 위치(허용 오차 = 눈금 보조 단위의 절반)·이웃한 점끼리의 선분·해석 선택·해석 문장
- 통과한 뒤에만 정답 비교 그래프 겹쳐 보기와 제출 가능

## 실행 방법 (Node.js 22.13 이상, 외부 패키지 없음)

```bash
npm start                 # http://localhost:3000
npm run dev               # 체험용 학급(DEMO26)까지 만들어서 시작
npm test                  # 서버 흐름 자동 검사
```

- 데이터베이스: 내장 SQLite(`node:sqlite`), 기본 위치 `data/graph-lab.sqlite`
- 체험용 학급: 학급 코드 `DEMO26`, 학생 1~20번(이름만 누르면 입장), 교사 `demo` / `demo1234` (가상 데이터, `DEMO_SEED=1`이거나 `npm run seed:demo` 실행 시에만 생성). **실제 수업 서버에서는 만들지 마세요.**

### 환경 변수

| 이름 | 설명 |
|---|---|
| `PORT` | 기본 3000 |
| `DATABASE_PATH` | SQLite 파일 경로. 배포 시 영구 디스크 위치로 지정 |
| `TEACHER_SIGNUP_CODE` | 정하면 이 코드를 아는 사람만 교사 계정을 만들 수 있음 (배포 시 꼭 정하세요) |
| `NODE_ENV=production` | 쿠키에 Secure 속성 적용(HTTPS 필수) |
| `DEMO_SEED=1` | 체험용 학급 자동 생성 |
| `NEIS_API_KEY` | 나이스 교육정보 개방 포털 인증키(선택). 없으면 나이스 정책상 학교 검색 결과가 5개까지만 나와요. [open.neis.go.kr](https://open.neis.go.kr)에서 무료로 발급 |

교사 비밀번호 재설정(서버에서 실행): `npm run reset-teacher -- <아이디> <새비밀번호>`

## 배포

SQLite 파일이 사라지지 않도록 **영구 디스크(볼륨)** 가 있는 곳에 배포해야 합니다.

- **Render**: 저장소를 연결하면 `render.yaml`로 웹 서비스 + 1GB 디스크가 설정됩니다(디스크는 유료 플랜). `TEACHER_SIGNUP_CODE`는 Render 대시보드의 Environment에서 확인하세요.
- **Railway / Fly.io / 학교 서버**: `Dockerfile` 사용, `/data`에 볼륨 연결.
- 반드시 HTTPS 주소로 서비스하세요.

GitHub에 올리기:
```bash
git remote add origin https://github.com/<계정>/kkukkeonseon-graph-lab.git
git push -u origin main
```

## 학급 만들기와 학생 접속(QR)
1. 교사 관리실 → **＋ 새 학급 만들기**
2. ① 학교 찾기(나이스 학교 정보, 검색이 안 되면 직접 입력) → ② 학년·반·학급 별명(학급 이름 자동) → ③ 학급 코드(자동 추천 또는 직접 정하기, 다른 학급과 겹치면 막음) → ④ QR 완성
3. QR은 `연구소주소/#join-학급코드` 주소를 담고 있어, 학생이 카메라로 비추면 학급 코드가 채워진 입장 화면이 열리고 내 이름만 누르면 돼요.
4. QR은 [크게 보기](전자칠판), [인쇄용 카드], [주소 복사]로 나눠 줄 수 있고, 학급 코드는 설정 탭에서 바꿀 수 있어요(바꾸면 예전 QR은 쓸 수 없음).

## 보안·개인정보
- 학생 로그인: 학급 코드 + 명단에서 내 이름 고르기(2026-11-23부터 PIN 없음 — 같은 반 친구가 다른 이름을 누를 수 있으니 수업 중 선생님이 지켜봐 주세요). 교사 비밀번호는 scrypt 해시로 저장, 세션은 HttpOnly 쿠키, 연속 실패 시 5분 제한
- 모든 요청에서 세션의 학급과 요청 자료의 학급을 서버가 대조 → 다른 학급 자료·전시관 접근 불가, 다른 교사의 학급 접근 불가
- 학생에게 보이는 참고 자료에는 이름이 없고, 19번 저축 금액은 학급 합계/평균만 공개(교사가 공개하지 않음 선택 가능)
- 쓰기 요청 CSRF 방지 헤더 검사, CSV 수식 주입 방지, 보안 헤더(CSP 등) 적용
- 기상자료는 학생이 직접 찾은 값을 입력하며, 프로그램에 실제 폭염일수를 넣어 두지 않았습니다.

## 구조

```
core/        서버 핵심 로직(권한·검증·집계) — 서버와 체험판이 함께 사용
server/      Node 웹 서버 (정적 파일 + /api)
public/      화면 (바닐라 JS 모듈, 빌드 과정 없음)
  shared/    주제 25개·단위·입력 제한, 통계 계산
  assets/    제공된 PNG 장식을 WebP로 최적화
demo/        체험판용: 브라우저 안 SQLite(sql.js)로 같은 core 실행
scripts/     체험판 빌드, 체험 학급 생성, 교사 비밀번호 재설정
tests/       서버 흐름 테스트
docs/        교사용 안내
```
